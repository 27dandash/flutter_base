# Neutral branding source

`neutral_app_icon.svg` and `neutral_launch_mark.svg` are generic, project-owned
placeholders used to generate the native launcher and launch-screen assets.
They contain no product or company branding. Every derived application must
replace them and regenerate all Android and iOS icon/splash surfaces before
store submission.

The source is tooling-only and is not declared in the root Flutter asset bundle.
