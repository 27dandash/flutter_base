# Example — Three or More Apps/Flavors

```text
{{APP_VARIANTS}} = consumer, merchant, courier, operations
{{FLAVORS}} = discover from entry points and native schemes
{{USER_ROLES}} = discover per app; do not collapse operations roles
{{FIGMA_URLS}} = shared design-system file plus four product files
{{COLLECTION_PATHS_OR_URLS}} = shared gateway collection plus service collections
{{BACKEND_ENVIRONMENTS}} = environment matrix to discover
{{TEST_ACCOUNTS}} = secure synthetic persona registry
```

Generate the matrix dynamically. Never copy a two-app table and silently drop
the third or later app.
