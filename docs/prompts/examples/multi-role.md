# Example — One App, Multiple Roles

```text
{{APP_VARIANTS}} = one marketplace app
{{FLAVORS}} = development, staging, production
{{USER_ROLES}} = guest, buyer, seller, support operator
{{FIGMA_URLS}} = shared design file with role pages
{{COLLECTION_PATHS_OR_URLS}} = shared collection with role scopes
{{BACKEND_ENVIRONMENTS}} = shared backend per environment
{{TEST_ACCOUNTS}} = one synthetic persona per role via secure handoff
```

The matrix uses one app and four roles. Shared screens stay shared; permissions
and role-only journeys remain explicit.
