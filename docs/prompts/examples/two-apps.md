# Example — Two Apps/Flavors

```text
{{APP_VARIANTS}} = customer app, provider app
{{FLAVORS}} = customerDevelopment/customerProduction, providerDevelopment/providerProduction
{{USER_ROLES}} = customer; provider owner, provider staff
{{FIGMA_URLS}} = shared library plus one file per app
{{COLLECTION_PATHS_OR_URLS}} = one collection with customer/provider folders
{{BACKEND_ENVIRONMENTS}} = shared staging and production clusters
{{TEST_ACCOUNTS}} = synthetic personas via secure handoff
```

Two is evidence here, not a template assumption. Branding may vary while tokens
and reusable components remain shared.
